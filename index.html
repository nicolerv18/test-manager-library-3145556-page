Gestión de biblioteca, del catálogo al reporte

Un sistema para mantener el catálogo de libros, los socios y los préstamos, y ver qué libros se prestan más. Pensado para una biblioteca pequeña.

Ver funcionalidades Cómo empezar

¿Qué es?

Manager Library es una aplicación web con un backend API y un frontend en React. El administrador y el bibliotecario entran con usuario y contraseña; los socios son datos, no usuarios.

Catálogo

Libros con ISBN único, categoría, ejemplares y portada opcional. Búsqueda parcial por título o autor.

Préstamos

De 1 a 3 libros distintos por socio, con 14 días de plazo y un máximo de 3 libros sin devolver.

Vencidos e informe

Lista de vencidos ordenada por días de retraso y el informe de libros más prestados por rango de fechas.

Funcionalidades

Cada pantalla cubre una historia de usuario del proyecto (HU-01 a HU-10).

Iniciar sesión

Autenticación con roles; cada acción se autoriza según el rol.

Gestionar libros

Crear, buscar, editar, subir o quitar portada y dar de baja (soft delete).

Gestionar socios

Alta, listado y búsqueda por nombre o documento.

Registrar préstamo

Selección de socio y de hasta 3 libros distintos, con validaciones claras.

Registrar devolución

Devolución por línea; el préstamo se cierra cuando todas vuelven.

Vencidos

Libros sin devolver con la fecha vencida y los días de retraso.

Informe de más prestados

Por rango de fechas inclusivo, con el título y la categoría congelados en el momento del préstamo.

Crear bibliotecarios

El administrador da de alta usuarios con rol de bibliotecario.

Roles

admin

Administrador

Mantiene el catálogo y los socios, crea bibliotecarios y ve todos los informes.

librarian

Bibliotecario

Registra préstamos y devoluciones; consulta catálogo, socios y vencidos.

member

Socio

Persona que toma prestados los libros. No inicia sesión: es data, no un usuario.

Stack

El spec se escribió para Python y .NET; el reto se resuelve con React y PHP (Laravel).

  • BackendPHP 8.3 + Laravel (solo API)
  • FrontendReact 18 + Vite + TypeScript
  • Base de datosPostgreSQL 16
  • ContenedoresDocker Compose

Cómo empezar

  1. Clonar los repositorios

    API, app, infra y tool, en carpetas hermanas.

  2. Levantar el entorno

    docker compose up arranca el motor de base de datos vacío, la API y el frontend.

  3. Preparar la base de datos

    Correr las migraciones de Laravel: crean las tablas y las cinco categorías.

  4. Cargar datos de demostración

    El sembrador (tool) crea socios y préstamos usando solo la API.

  5. Abrir la aplicación

    Entrar en el frontend e iniciar sesión como administrador o bibliotecario.
